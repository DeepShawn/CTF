# 工具清单（对照教材章节）

[← 返回计划总览](README.md)

本清单按参考教材第 0～8 章逐节列出工具包中对应的内容。章节编号与教材目录一致，便于对照查找。

“可用端”一栏的含义：

| 标记 | 含义 |
|---|---|
| **全端** | Web、Android、iOS 离线可用，Docker 环境中也可用（`ctfkit` 命令行） |
| **全端（小文件）** | 同上，但手机端只建议处理较小的文件，大文件提示改用 Docker |
| **Docker** | 依赖命令行工具或 C 扩展库，只在 Docker 完整环境中运行；三端显示原理、命令参考，并可通过本地运行器调用 |
| **速查** | 原理说明、载荷与命令参考，不执行任何操作，全端可看 |

“版本”一栏是计划中实现该项的版本，见[版本路线](README.md#7-版本路线)。
